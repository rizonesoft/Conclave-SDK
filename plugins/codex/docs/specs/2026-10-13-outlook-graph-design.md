# Outlook Graph connector

The user authorised a separate Graph plugin to close the curated Outlook connector's metadata and filing gaps. Source is `outlook-graph/`, independent of other agents. Official TickTick remains the task connector. This plugin owns Graph access and verification; the two global skills own business decisions and formatting.

Use delegated public-client OAuth through Microsoft MSAL Node with User.Read, Mail.ReadWrite and MailboxSettings.Read. No Mail.Send, application permissions, generic HTTP, sending or deletion tools. Bind the session to the configured mailbox. Windows stores the entire MSAL record using DPAPI CurrentUser outside Git with restricted ACLs. Native WSL uses that Windows account's DPAPI helper through a private pipe. Ubuntu cloud uses an AES-GCM cache key delivered by systemd LoadCredentialEncrypted, with private service state. No runtime vault access. Conclave stores registration metadata; recover OAuth by signing in again.

Expose explicit message reads with permanent identity, bounded folder/message pagination, conversation and Sent Items reads, existing categories, and EWS-to-REST ID translation. Provider continuation links become opaque server-held cursors, never arbitrary user URLs. Requests pin graph.microsoft.com, reject redirects and bound response size, timeout and read retries. Writes are never retried automatically.

Changes require a ten-minute, single-use stored preview with full body and recipient details, mailbox, current message identity/change key and exact target. Revalidate immediately before execution and consume before awaiting writes. Drafts are plain-text bodies with no generated signatures. Reply recipients are explicit and verified. A filing change only accepts mail directly in Inbox and a destination evidenced by an earlier message from the same sender or conversation. Preserve existing categories and add only the existing TickTick category. Move and category update are separate Graph writes within one tool execution, with identity and state read-back. Partial or uncertain results stop dependent work and return recovery context; they never claim atomicity or success.

Tests cover pagination, credential isolation, HTTP errors, redirects, limits, preview expiry, replay/concurrency, changed state, prohibited routes/folders, duplicate category preservation, recipient/body verification and uncertain writes. Live verification is read-only until separately authorised mailbox changes. Install through the local Rizonetech marketplace and update both global skills to prefer this explicit connector when authenticated. Cloud hosting follows the existing conclave-srv and private tunnel convention when its setup prerequisites are available.
