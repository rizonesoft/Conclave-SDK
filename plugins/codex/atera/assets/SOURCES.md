# Atera brand asset sources

Retrieved 2026-10-05 from Atera's official API documentation portal:

- Original favicon: https://api.atera.com/devportal/assets/atera-favicon.ico
- Original vector wordmark: https://api.atera.com/devportal/assets/Atera_Logo_White.svg
- Source page: https://api.atera.com/devportal/

`atera-official.ico` and `atera-official-wordmark.svg` preserve the downloaded originals. `icon.svg` uses the unchanged vector artwork, with a square viewport isolating the left-hand Atera symbol and the portal's official primary color `#ff176b`, matching its favicon. `icon.png` is the 512 x 512 render used by the plugin listing and composer; regenerate with `npm run icons`.

Atera's name and logo belong to Atera. The integration is independently developed by Rizonetech and does not imply Atera endorsement.
