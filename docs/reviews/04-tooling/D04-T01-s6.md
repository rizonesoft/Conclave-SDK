Dropping late responses and limiting individual messages leaves these accumulators untouched during a long session, particularly when a server stops reading. 6. **P2, line 235: Shutdown proof omits shutdown during work.** EOF and SIGTERM tests can pass if they only stop an idle bridge. A bridge blocked waiting for diagnostics can miss EOF until the agent forcibly terminates it.
