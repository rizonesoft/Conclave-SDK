### adversarial: needs-attention

1. **P1: Accepted regexes can hang the checker indefinitely.** `kits/toolchain-cpp/templates/scripts/toolchain-check.py:259` runs the pin’s regex outside the subprocess deadline. Reproduce with an installed `python`, `version_args: ["--help"]`, `version_pattern: "(?:[^\\n]+)+([0-9]+)$"` and `min_version: "1"`. The loader accepts this pin, but matching the ordinary help output causes catastrophic backtracking. A probe with a 0.5-second tool limit still required termination by an external three-second watchdog. Bound regex evaluation itself.

2. **P2: Cancellation leaves tool processes running.** `kits/toolchain-cpp/templates/scripts/toolchain-check.py:214` has no enclosing `finally` for process-tree cleanup. Pressing Ctrl+C while a version command is waiting raises `KeyboardInterrupt` from the join, bypassing `_end_tree` and pipe closure. The subprocess has its own session/process group, so cancellation does not reliably reach it. Injecting that interruption at the wait boundary confirmed zero cleanup calls. Put cleanup in an exception-safe lifecycle.

### integration: needs-attention

3. **P2: An accepted numeric minimum aborts the entire report.** `kits/toolchain-cpp/templates/scripts/toolchain-check.py:137` converts arbitrarily long digit strings using `int()`. On the current Python runtime, checking it raises an uncaught `ValueError` concerning the 4,300-digit conversion limit. Subsequent tools are never checked, and the CLI emits neither the promised JSON report nor a controlled pin refusal. Confirmed with an in-memory pin-file probe.

4. **P2: Deeply nested regex input escapes the pin-error contract.** `kits/toolchain-cpp/templates/scripts/toolchain-check.py:77` catches only `re.error`. A pattern constructed as `"(?:“ * 1000 + "(1)" + ")" * 1000` (using ordinary ASCII quotes in the expression) raises `RecursionError` during compilation. Confirmed through `load_pins`; the CLI catches only `PinError`, so this produces a traceback and exit 1 instead of the required one-line refusal and exit 2. Catch compilation resource failures and reject excessive nesting.
