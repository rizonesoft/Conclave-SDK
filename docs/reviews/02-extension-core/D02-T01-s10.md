1. Regression with a run hook that lets the todo dry run read the folder, then holds its answer while the folder changes and is invalidated: both reads answer with the fresh state and at most one dry run is ever in flight; running once fails the first assertion, and dropping the queue fails the second.
2. Settings: any `conclave` setting change and a granted workspace trust invalidate every known folder, and a folder's Python resolving to something other than what its state was computed with invalidates that folder (the first resolution is not a change: treating it as one dropped the first state at once, which the cache test caught). Regression: a state read with a broken `conclave.pythonPath` recovers once the setting is corrected; with neither listener it stays failed.
