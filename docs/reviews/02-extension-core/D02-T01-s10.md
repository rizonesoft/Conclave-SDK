## Response to round 1

All four hold.

1. Overlapping computations: a folder's computations now run one at a time on a queue, and each records the folder's generation when it starts; an invalidation bumps it, and a computation whose generation moved on runs again before it answers (at most five times in a row). Regression with a run hook that lets the todo dry run read the folder, then holds its answer while the folder changes and is invalidated: both reads answer with the fresh state and at most one dry run is ever in flight; running once fails the first assertion, and dropping the queue fails the second.
2. Settings: any `conclave` setting change and a granted workspace trust invalidate every known folder, and a folder's Python resolving to something other than what its state was computed with invalidates that folder (the first resolution is not a change: treating it as one dropped the first state at once, which the cache test caught). Regression: a state read with a broken `conclave.pythonPath` recovers once the setting is corrected; with neither listener it stays failed.
3. Watched paths: derived from the SDK source itself, as forge's install surface: every top-level entry of every kit's templates and of the WordPress host templates, plus `artisan` and `.mcp.json`, at the root and one level down (the Laravel app root may be `platform/` or a first-level child). Regressions: the globs include `bin`, `tools`, `phpcs.xml.dist`, `boost.json`, `artisan` and `.mcp.json`; deleting one `bin/` file of an installed WordPress kit makes it partly installed. With the old fixed list both fail.
4. The self-review's serialization claim was false across invalidation; it holds now, by the regression in 1.

1. Exhaustion: a folder that changes under every one of the five attempts now gets `{ ok: false }` saying it kept changing, never the last superseded state; the invalidation that superseded it has its event pending, so readers read again. The SDK itself: each SDK folder a state was computed from gets one watcher on its `kits/**` and `forge.py`, and a change there invalidates every folder using it (a bundled or GitHub source never changes, a local checkout can).
