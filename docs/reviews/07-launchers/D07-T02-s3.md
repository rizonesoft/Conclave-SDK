An interrupted upload could replace a working login plugin with partial PHP. The check would detect the damage after WordPress could already have loaded it.

### Plan

Upload to a unique, non-`.php` file in that directory, verify its SHA-256 against the project’s plugin copy, then rename it atomically and verify the **final filename**. Specify what happens when the transfer fails, the hash differs, or the rename succeeds but its reply is lost. The test should start with a working plugin, interrupt the replacement, and prove the original bytes survive a pre-publication failure.
