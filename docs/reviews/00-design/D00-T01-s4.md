## Response to round 1

All six findings hold.

1. Stale check race: the hash is now compared as the last step before the rename and again before every Windows retry, after the temporary file is written; a file watcher marks the editor stale as soon as the pin changes. The remaining instant between the last check and the rename is stated with why it stays (no lock other editors honour; VS Code's own save has it).
2. Extraction: the archive's member list is the check, before anything is written: any non-regular member (symlink, hard link, device, FIFO), absolute name (leading `/` or `\`, drive letter), `..` segment on either separator, or a member outside the single top folder refuses the whole archive. `filter="data"` stays as a second layer, and the spec says why it is not enough alone. The extractor ships in the `.vsix` and runs with `-I`.
3. Layout: `load_pin` accepts layouts the editor cannot edit in place. The spec now defines the one layout it edits; any other valid pin opens a read-only `pin-layout` state, applied to the mockup first (`e37bd70`, `design/decisions.md` 2026-10-20) and owned by new items in `D02 T01 §3` and `§4`, `D03 T01 §10` and `§11`, and `D06 T01 §4`.
4. Workspace trust: `supported: "limited"` with the four settings as `restrictedConfigurations`, so the extension activates in Restricted Mode and shows the state, and one `isTrusted` guard covers the function that spawns processes.
5. Examples: every edit (nine, including adding and removing a field and adding a route) is a unified diff of the whole shipped pin, generated by `design/spikes/pin_edits.py`, which checks the before and after with `load_pin` and the CRLF copy; it exits 1 when an edit leaves a pin `load_pin` refuses.
6. Spike: run with the owner's choice (asked in the session: "Run the spike now"), over the shipped pin, a commented copy and an inline-table pin, six libraries (`design/spikes/toml_libraries.mjs`). No library edits every case in place: three lose all comments; `@decimalturn/toml-patch` adds a reviewer as a dotted inline key under another reviewer's comment and deletes the `[routes]` comment when deleting `sonnet`; `toml-patch` is unmaintained and fails on inline tables; `toml-eslint-parser` has no writer. The hand-written editor is chosen on that evidence; the section's Corrected note says so.
