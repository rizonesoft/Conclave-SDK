## Lessons

- When repairing a completion gap, commit `- Implemented:` in the repair candidate itself (`$c_cand`) alongside the code/test fix and supply fresh green 3-job CI logs via `--gates` (`build/`) so the repair needs only one CI run and never invalidates its candidate SHA after green CI.
- On Python 3.12+, `unittest discover` on an empty folder prints `Ran 0 tests in 0.000s` and exits `5`: evaluate `result["tests"] == 0` before generic nonzero exit reporting so `check-all` preserves the actual exit code while consistently surfacing `no tests ran`.
- `todo_graph.section_contract` requires every pass from Plan Review through Stamp to see identical non-neutralized contract text: archive superseded findings files intact and record contract updates before `$c_plan` so later code fixes never mutate the section text.
- Python `unittest discover` silently skips `test_*.py` files whose stem is not a valid Python identifier (`unittest.loader.VALID_MODULE_NAME`, e.g. `test_sync-conflicts.py`), so test-inventory ownership checks must enforce `^[_a-z]\w*\.py$` (`re.IGNORECASE`) alongside `__init__.py` package chains.
