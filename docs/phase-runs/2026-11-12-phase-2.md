## Lessons

- A check over `scripts/` that passes in the kit can fail in an installed project, where `scripts/` also holds the other kits' files: after changing a kit's tests, run `python -m unittest tests.test_forge.UnattendedKitTests` (the installed copy) before the quick suite. Found 2026-11-12 when `WindowlessTest` scanned `todo_graph.py` and `merge_prs.py`.
- A re-plan of a section already built restarts its build: the re-plan commit writes a new `Started:` line (the old one kept in a dated note), or the stamp refuses the later plan review as after the build began. Found 2026-11-12 stamping `D02 T02 §7`.
- Suites never run on a clean runner hide platform assumptions (8.3 temp paths, a Windows-only launcher, tmux present, no Codex): a project's CI should run its suites on every platform it claims from its first commit. Found 2026-11-13 when the SDK's first CI run was red on all three jobs.
