## Lessons

- A PowerShell commit message holding `\"` fails to parse and nothing runs, while the next command still runs: commit messages with quotes go through a message file (`git commit -F`).
- `git checkout --` cannot restore an untracked file: a mutation test on a new file restores from a saved copy.
- Reviews keep finding real defects in round 2 and 3 on security-sensitive code (archive extraction, temporary files): each round's fix gets its own regression test that failed first, measured, not asserted.
- An extractor hardened by patching one `tarfile` feature per review round never converges: after six rounds the fix is structural (check each member as read, allow only git's subset), not a seventh patch.
- A watcher test that writes at once can race VS Code's asynchronous watcher start: probe the watcher before blaming paths; here every watcher shape worked once started.
