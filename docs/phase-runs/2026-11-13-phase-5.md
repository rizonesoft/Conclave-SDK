## Lessons
- A test changed after its last Linux run is run on Linux again before the push: a stand-in for a standard-library function must take every argument its real callers pass.
- A mutation check that passes is read before it is believed: here it exposed a wait the code only appeared to bound. A cleanup test uses a real holder, not a patched `communicate`.
- A proof run in WSL on `/mnt/d` says nothing about file modes: only CI's Linux checkout (or a clone on a Linux filesystem) does.
