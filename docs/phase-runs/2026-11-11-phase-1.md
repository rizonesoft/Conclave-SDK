## Lessons

- A file and its record cannot be written atomically together, and each "write one, then the other" order drew a new finding. The design that closed the loop was a journal plus a rename as the commit step. Reach for that first when two files must agree.
- In a Bash heredoc that feeds Python, an escaped newline inside a Python string can arrive as a real line break and break the code. Put such code in a scratch file or use the Edit tool.
- After the round's fixes, record the checkpoint, the quick suite and the section's named mutation, run at the final candidate, in the findings file under a `## Writer note:` heading before asking for the completion review. Three times (§6, §7, §8) the completion review's only gap was that evidence, which cost a reconciliation each time. Run the Test checkpoint's own named mutation, word for word, not a near one.
- Sync the plan (`plan --sync`) after ticking checklist items and before the quick suite: `test_the_repository_graph_validates_and_its_plan_is_current` fails on a stale plan.
