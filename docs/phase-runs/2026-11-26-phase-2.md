## Lessons

- Always verify external CLI behavior directly against its source (`helio.c:180,189,527,872` and `store.c:844-850`) before writing skill contracts or stub tests; `helio show` does not expose a future `--due` deadline and `OVERDUE` does not unlock `take`.

- On clean Windows CI runners, `subprocess.run(["tool.cmd", ...], env=child_env)` resolves the executable against the parent process `PATH`; pass the fixture stub's absolute path when testing lifecycle commands while keeping shell guard fences on `PATH`.
