## Lessons
- A reader that exists twice (in two languages, or as a copy) drifts on every axis its parsers differ on; the class closed only when one reader served every caller (`D02 T02 §12`, reconciliations 7 to 15). When a gap reopens, look first for the duplicate that produces it.

- A change to forge.py's help text or kit list is read by tests in five files (`test_forge`, `test_lsp_kit`, `test_toolchain_kits`, `test_kit_install`, `test_reviewer_flags`): run every test that calls `--help` before pushing such a change, not only the section's own `-k` selection.
- `review-dispatch.py` takes no pass after a section's reconciliation ends complete, so a red-CI fix found after it cannot join the section's chain: the section stamps at the reconciled candidate, and the fix gets its own review outside the section (a findings file not named for a section) before the stamp cites the green run that includes it.
