## Lessons

- A stamp commit pushed while CI runs on the candidate cancels that run (the workflow's concurrency), and the stamp then has no green run to cite: wait for the candidate's run, then push the stamp.
- PowerShell reads `-Wl,a,b` as an array argument; quote linker options passed to a native compiler from PowerShell.
- A distro's compiler defaults (Ubuntu's GCC: stack protector, `_FORTIFY_SOURCE=3`, PIE, `-z now`) are invisible to a compile-command check; the guidance says to declare each option in the build.
